# Texting the Assistant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user text the blimp assistant from Messages: a relay on a Mac carries texts to blimpd, blimpd types them into the assistant and texts its answers and questions back.

**Architecture:** `relay/` is a small Bun program compiled for the Mac. It reads new texts from Messages' database, POSTs them to blimpd, long-polls blimpd for texts to send, and sends them with osascript. `src/messages/` is blimpd's side:
- the switch, the relay key and a state file (`store.ts`);
- the words texted and the reading of yes/no replies (`words.ts`);
- a 1 s loop that turns the assistant's finished turns and questions into outgoing texts and types held texts in (`texter.ts`);
- the CLI (`cli.ts`).

`server.ts` adds three `/messages/` routes that only the relay key reaches.

**Tech Stack:** Bun 1.4 (TypeScript, `bun:sqlite`, `bun:test`), osascript/AppleScript on macOS, launchd.

**Spec:** docs/superpowers/specs/2026-10-26-messages-design.md

## Global Constraints

- Work only in the worktree `/Users/mbeato/blimp-messages` (branch `messages`). Never touch `/Users/mbeato/blimp`; other sessions use it.
- Bun is at `~/.bun/bin/bun` if `bun` isn't on PATH. Tests live in `test/` (bunfig.toml `root = "test"`), use `bun:test`, and the full suite is `bun test` from the worktree root.
- The relay uses no npm packages: only Bun and Node built-ins (`bun:sqlite`, `node:fs`, …). It is built with `bun build relay/main.ts --compile --target=bun-darwin-arm64 --outfile dist/blimp-relay`.
- blimp is open source. No personal names, numbers or addresses in code, user-facing strings, blimp.md or tests. Say "the user". Test handles are `+15550000000` and `user@example.com`.
- These user-facing strings are exact and live in `src/messages/words.ts`:
  - `OFF` = `The assistant is off. Turn it on in blimp's Settings.`
  - `PICTURE_ONLY` = `I can only read text for now.`
  - `PICTURE_NOTE` = ` (a picture came with this text; you can't see pictures yet)`
  - `ALREADY` = `That was already answered.`
  - `OPEN_BLIMP` = `It's asking something only blimp can show. Open blimp to answer.`
  - `OFFLINE` = `The Messages relay is offline: blimp hasn't heard from it in 5 minutes. Check the Mac it runs on.`
  - The echo reply is `got: <text>`.
- The relay key is `<socket dir>/relay-key`: 32 random bytes as hex, mode 600. It reaches only paths starting `/messages/`, and every other key gets 401 on those paths. While texting is off, every `/messages/` route answers 403 `{"error":"messages is off"}`.
- Every file blimpd writes for this goes through a temp file and a rename, with mode 600.
- Each new file opens with a comment saying what it does, pointing at the spec. Match the surrounding style: short plain sentences, comments only where they say something the code doesn't.
- Commit messages are plain, in the repo's style ("blimpd: …", "relay: …", "Docs: …"). No Co-Authored-By or any Claude attribution line.

// Reading new texts from Messages' database on the Mac (docs/superpowers/specs/2026-10-26-messages-design.md,
// section 1): read-only, the rows after the last one read. Only texts from an allowed handle, in a one-to-one
// chat, that aren't the account's own or a reaction, ever leave this file.

import { Database } from "bun:sqlite";

export type Incoming = { id: string; from: string; text: string; picture: boolean };

// chat.style for a one-to-one chat; group chats are 43.
const DIRECT = 45;

export const openChatDb = (file: string) => new Database(file, { readonly: true });

// The newest row now: where a first run starts, so old history is never sent.
export function watermark(db: Database): number {
  return db.query<{ max: number | null }, []>("SELECT MAX(ROWID) AS max FROM message").get()?.max ?? 0;
}

type Row = { rowid: number; guid: string; text: string | null; body: Uint8Array | null; mine: number; reaction: number | null; pics: number; handle: string | null; style: number };

// Texts after row `after` that may go to blimpd, and the last row read: skipped rows count, so they're never read
// again. allow: handles as chat.db writes them (+15551234567, name@example.com), in any case.
export function newTexts(db: Database, after: number, allow: string[]): { last: number; texts: Incoming[] } {
  const rows = db
    .query<Row, [number]>(
      `SELECT m.ROWID AS rowid, m.guid, m.text, m.attributedBody AS body, m.is_from_me AS mine,
              m.associated_message_type AS reaction, m.cache_has_attachments AS pics, h.id AS handle, c.style
       FROM message m
       JOIN chat_message_join cmj ON cmj.message_id = m.ROWID
       JOIN chat c ON c.ROWID = cmj.chat_id
       LEFT JOIN handle h ON h.ROWID = m.handle_id
       WHERE m.ROWID > ?
       ORDER BY m.ROWID ASC`,
    )
    .all(after);
  const allowed = new Set(allow.map((a) => a.toLowerCase()));
  const taken = new Set<number>();
  let last = after;
  const texts: Incoming[] = [];
  for (const r of rows) {
    last = Math.max(last, r.rowid);
    if (taken.has(r.rowid) || r.mine || r.reaction || r.style !== DIRECT || !r.handle || !allowed.has(r.handle.toLowerCase())) continue;
    taken.add(r.rowid);
    // U+FFFC marks where an attachment sits in the text.
    const text = (r.text ?? decodeBody(r.body) ?? "").replace(/￼/g, "");
    const picture = r.pics === 1;
    if (!text.trim() && !picture) continue;
    texts.push({ id: r.guid, from: r.handle, text, picture });
  }
  return { last, texts };
}

// Newer macOS keeps the text in attributedBody (a typedstream NSAttributedString) when `text` is NULL: the
// NSString's bytes after the '+' that starts them, behind a length (0x81, 0x82, 0x83: a 1, 2 or 3-byte
// little-endian length follows). Adapted from the official Claude Code iMessage plugin
// (github.com/anthropics/claude-plugins-official, external_plugins/imessage, Apache-2.0).
export function decodeBody(blob: Uint8Array | null): string | undefined {
  if (!blob) return undefined;
  const buf = Buffer.from(blob);
  let i = buf.indexOf("NSString");
  if (i < 0) return undefined;
  i += "NSString".length;
  while (i < buf.length && buf[i] !== 0x2b) i++;
  if (++i >= buf.length) return undefined;
  const b = buf[i++];
  let len = b;
  if (b === 0x81) {
    len = buf[i];
    i += 1;
  } else if (b === 0x82) {
    len = buf.readUInt16LE(i);
    i += 2;
  } else if (b === 0x83) {
    len = buf.readUIntLE(i, 3);
    i += 3;
  }
  return i + len <= buf.length ? buf.toString("utf8", i, i + len) : undefined;
}

import type { Incoming } from "../relay/chatdb";
import { inStep, outStep, parseConfig, parseState, type RelayDeps } from "../relay/relay";
import { SEND_SCRIPT, sendText } from "../relay/send";

const hi = (id: string, text = "hi", from = "+15550000000"): Incoming => ({ id, from, text, picture: false });

function setup(o: { server?: boolean; texts?: Incoming[]; answer?: (path: string, init?: RequestInit) => Response | Promise<Response> } = {}) {
  const t = {
    texts: o.texts ?? [],
    reads: [] as number[],
    sent: [] as [string, string][],
    sendFails: undefined as string | undefined,
    calls: [] as { path: string; init?: RequestInit }[],
    saves: 0,
    logs: [] as string[],
  };
  const d: RelayDeps = {
    config: { allow: ["+15550000000"], ...(o.server && { server: "https://blimp.example", key: "k" }) },
    state: { pending: [] },
    save: () => void t.saves++,
    watermark: () => 40,
    read: (after) => {
      t.reads.push(after);
      const texts = t.texts;
      t.texts = [];
      return { last: after + texts.length, texts };
    },
    send: (text, to) => {
      if (t.sendFails) return t.sendFails;
      t.sent.push([text, to]);
      return undefined;
    },
    fetch: async (path, init) => {
      t.calls.push({ path, init });
      return (await o.answer?.(path, init)) ?? Response.json({ ok: true });
    },
    log: (m) => void t.logs.push(m),
    sleep: async () => {},
  };
  return { t, d };
}

// Sending a text through Messages (docs/superpowers/specs/2026-10-26-messages-design.md, section 1): osascript, with
// the text and the handle as arguments, never pasted into the script, to the handle's conversation on the
// account's iMessage service.

export const SEND_SCRIPT = `on run argv
  tell application "Messages"
    set s to 1st account whose service type = iMessage
    send (item 1 of argv) to participant (item 2 of argv) of s
  end tell
end run`;

export type Run = (cmd: string[], stdin: string) => { code: number; err: string };

const osascript: Run = (cmd, stdin) => {
  const r = Bun.spawnSync(cmd, { stdin: new TextEncoder().encode(stdin), stdout: "ignore", stderr: "pipe" });
  return { code: r.exitCode ?? 1, err: r.stderr.toString().trim() };
};

// Undefined once sent, or why not.
export function sendText(text: string, to: string, run: Run = osascript): string | undefined {
  const r = run(["osascript", "-", text, to], SEND_SCRIPT);
  return r.code === 0 ? undefined : r.err || `osascript exited ${r.code}`;
}
```

// The relay's work (docs/superpowers/specs/2026-10-26-messages-design.md, sections 1 and 3), apart from its files and
// the clock so tests can drive it.
// - In: new texts from chat.db go to blimpd (POST /messages/in) in order, each kept in the state file until blimpd
//   has it. With no server in relay.json they go straight back as "got: <text>" (echo mode, for testing the Mac on
//   its own).
// - Out: blimpd's texts to send (GET /messages/out, held up to 25 s), each sent through Messages and then marked
//   sent.

import type { Incoming } from "./chatdb";

export type Config = { server?: string; key?: string; allow: string[] };
// last: the last chat.db row read. to: whom to text, the sender of the latest allowed text. pending: texts in that
// blimpd doesn't have yet.
export type State = { last?: number; to?: string; pending: Incoming[] };

export type RelayDeps = {
  config: Config;
  state: State;
  save: (s: State) => void;
  watermark: () => number;
  read: (after: number) => { last: number; texts: Incoming[] };
  send: (text: string, to: string) => string | undefined;
  // A request to blimpd: a path under config.server, sent with the key.
  fetch: (path: string, init?: RequestInit) => Promise<Response>;
  log: (m: string) => void;
  sleep: (ms: number) => Promise<void>;
};

// relay.json's text. allow: the handles whose texts may reach blimpd. A server needs its key.
export function parseConfig(text: string): Config {
  const c = JSON.parse(text);
  if (!c || typeof c !== "object" || !Array.isArray(c.allow) || !c.allow.length || !c.allow.every((a: unknown) => typeof a === "string" && a.trim()))
    throw new Error("relay.json: allow must list the handles (+15551234567, name@example.com) whose texts may reach blimpd");
  if (c.server !== undefined && (typeof c.server !== "string" || !/^https?:\/\//.test(c.server) || typeof c.key !== "string" || !c.key))
    throw new Error("relay.json: server must be blimpd's https:// address, with its key");
  return { server: c.server?.replace(/\/+$/, ""), key: c.key, allow: c.allow.map((a: string) => a.trim()) };
}

// state.json's text; what's missing or broken starts empty.
export function parseState(text?: string): State {
  try {
    const s = JSON.parse(text ?? "");
    return { last: typeof s?.last === "number" ? s.last : undefined, to: typeof s?.to === "string" ? s.to : undefined, pending: Array.isArray(s?.pending) ? s.pending : [] };
  } catch {
    return { pending: [] };
  }
}

// One look at chat.db, then delivery of what's waiting.
export async function inStep(d: RelayDeps): Promise<void> {
  const s = d.state;
  s.last ??= d.watermark();
  const { last, texts } = d.read(s.last);
  if (last !== s.last || texts.length) {
    s.last = last;
    for (const t of texts) {
      s.to = t.from;
      s.pending.push(t);
    }
    d.save(s);
  }
  if (!d.config.server) {
    while (s.pending.length) {
      const t = s.pending[0];
      const err = d.send(`got: ${t.text}`, t.from);
      if (err) return d.log(`couldn't send a text: ${err}`);
      s.pending.shift();
      d.save(s);
    }
    return;
  }
  while (s.pending.length) {
    let r: Response;
    try {
      r = await d.fetch("/messages/in", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(s.pending[0]), signal: AbortSignal.timeout(15_000) });
    } catch (e) {
      return d.log(`blimpd can't be reached (${(e as Error).message}); trying again`);
    }
    if (r.status === 401) return d.log("blimpd refused the key in relay.json; texts wait until it's fixed");
    if (r.status >= 500) return d.log(`blimpd said ${r.status}; trying again`);
    if (!r.ok) d.log(`blimpd said ${r.status} (${await r.text()}); skipped a text`);
    s.pending.shift();
    d.save(s);
  }
}

// One round out: what blimpd has to send, each sent and then marked sent. Throws when blimpd can't be reached or
// says no, or a send fails; whatever wasn't marked sent comes again next round.
export async function outStep(d: RelayDeps): Promise<void> {
  const r = await d.fetch("/messages/out?wait=25", { signal: AbortSignal.timeout(40_000) });
  if (!r.ok) throw new Error(`blimpd said ${r.status}`);
  const { texts } = (await r.json()) as { texts: { id: string; text: string }[] };
  for (const t of texts) {
    const err = d.send(t.text, d.state.to ?? d.config.allow[0]);
    if (err) throw new Error(`couldn't send a text: ${err}`);
    const done = await d.fetch(`/messages/out/${encodeURIComponent(t.id)}/sent`, { method: "POST" });
    if (!done.ok) throw new Error(`blimpd said ${done.status} to a sent text`);
  }
}

// In, every 2 s, for ever.
export async function inLoop(d: RelayDeps): Promise<never> {
  for (;;) {
    try {
      await inStep(d);
    } catch (e) {
      d.log(`reading texts: ${(e as Error).message}`);
    }
    await d.sleep(2000);
  }
}

// Out, round after round; after a failure the gap grows from 2 s to at most a minute.
export async function outLoop(d: RelayDeps): Promise<never> {
  let gap = 0;
  for (;;) {
    try {
      await outStep(d);
      gap = 0;
    } catch (e) {
      d.log((e as Error).message);
      gap = Math.min(gap ? gap * 2 : 2000, 60_000);
      await d.sleep(gap);
    }
  }
}

// blimpd. It runs as a LaunchAgent in the Mac user whose Messages is signed in to the assistant's Apple ID. Its
// folder (the binary's, or $BLIMP_RELAY_DIR) holds relay.json ({"server", "key", "allow"}; no server means echo
// mode) and state.json. Its log is ~/Library/Logs/blimp-relay.log.

import { appendFileSync, mkdirSync, readFileSync, renameSync, writeFileSync } from "node:fs";
import { homedir } from "node:os";
import { dirname, join } from "node:path";
import { newTexts, openChatDb, watermark } from "./chatdb";
import { inLoop, outLoop, parseConfig, parseState, type RelayDeps, type State } from "./relay";
import { sendText } from "./send";

const dir = process.env.BLIMP_RELAY_DIR || dirname(process.execPath);
const logs = join(homedir(), "Library", "Logs");
let lastLine = "";
// A line repeated right after itself is written once, so a relay that keeps failing doesn't fill the disk.
function log(m: string) {
  if (m === lastLine) return;
  lastLine = m;
  mkdirSync(logs, { recursive: true });
  appendFileSync(join(logs, "blimp-relay.log"), `${new Date().toISOString()} ${m}\n`);
}

const read = (file: string) => {
  try {
    return readFileSync(file, "utf8");
  } catch {
    return undefined;
  }
};
const stateFile = join(dir, "state.json");
function save(s: State) {
  writeFileSync(stateFile + ".tmp", JSON.stringify(s), { mode: 0o600 });
  renameSync(stateFile + ".tmp", stateFile);
}

try {
  const text = read(join(dir, "relay.json"));
  if (text === undefined) throw new Error(`no relay.json in ${dir}`);
  const config = parseConfig(text);
  // Without Full Disk Access this throws ("authorization denied"); launchd starts the relay again 30 s later.
  const db = openChatDb(join(homedir(), "Library", "Messages", "chat.db"));
  const d: RelayDeps = {
    config,
    state: parseState(read(stateFile)),
    save,
    watermark: () => watermark(db),
    read: (after) => newTexts(db, after, config.allow),
    send: (t, to) => sendText(t, to),
    fetch: (path, init = {}) => fetch(config.server + path, { ...init, headers: { ...(init.headers as Record<string, string>), Authorization: `Bearer ${config.key}` } }),
    log,
    sleep: (ms) => Bun.sleep(ms),
  };
  log(`started, ${config.server ? `with blimpd at ${config.server}` : "in echo mode"}`);
  if (config.server) void outLoop(d);
  await inLoop(d);
} catch (e) {
  log(`stopped: ${(e as Error).message}`);
  process.exit(1);
}

```ts
// Texting the assistant (docs/superpowers/specs/2026-10-26-messages-design.md): the switch in config.json
// ({"messages": {"on": true}}), the relay's key (<socket dir>/relay-key), and the state file (<socket
// dir>/messages.json). The state file holds:
// - texts waiting to go out;
// - ids of texts already taken in;
// - texts held for the assistant;
// - what's been texted of its replies and questions;
// - when the relay last called.
// Every change reads, changes and writes the file in one synchronous step, so the server's routes and the
// texter's tick never lose each other's changes.

import { randomBytes, randomUUID } from "node:crypto";
import { chmodSync, readFileSync, renameSync, rmSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { configFile, readConfig, saveConfig } from "../names";
import { blimpDir } from "../sessions";

export type Out = { id: string; text: string; at: number };
export type MessagesState = {
  outbox: Out[];
  seen: string[]; // ids of texts taken in, newest last, at most SEEN
  held: string[]; // texts to type into the assistant once it isn't asking anything
  primed?: boolean; // sentReply was set when texting began, so a reply from before isn't texted
  sentReply?: string; // the id of the assistant's latest reply that was texted (or primed)
  lastWait?: number; // prompt.at of the latest question texted
  open?: boolean; // that question is still to be answered from Messages
  relaySeen?: number; // when the relay last called (ms), for `blimpd messages status`
};

export const SEEN = 500;
export const messagesFile = (dir = blimpDir()) => join(dir, "messages.json");
export const relayKeyFile = (dir = blimpDir()) => join(dir, "relay-key");

export const messagesOn = (file = configFile()) => (readConfig(file) as { messages?: { on?: unknown } }).messages?.on === true;

export function readState(file = messagesFile()): MessagesState {
  try {
    const v = JSON.parse(readFileSync(file, "utf8"));
    if (v && typeof v === "object" && !Array.isArray(v))
      return { ...v, outbox: Array.isArray(v.outbox) ? v.outbox : [], seen: Array.isArray(v.seen) ? v.seen : [], held: Array.isArray(v.held) ? v.held : [] };
  } catch {}
  return { outbox: [], seen: [], held: [] };
}

// Reads the state, lets f change it, writes it back (temp file, rename, 600) and returns what f returned.
export function change<T>(f: (s: MessagesState) => T, file = messagesFile()): T {
  const s = readState(file);
  const r = f(s);
  writeFileSync(file + ".tmp", JSON.stringify(s), { mode: 0o600 });
  chmodSync(file + ".tmp", 0o600);
  renameSync(file + ".tmp", file);
  return r;
}

export const pushOut = (s: MessagesState, text: string, now: number) => void s.outbox.push({ id: randomUUID(), text, at: now });
export const addOut = (text: string, now = Date.now(), file = messagesFile()) => change((s) => pushOut(s, text, now), file);
export const markSent = (id: string, file = messagesFile()) => change((s) => void (s.outbox = s.outbox.filter((o) => o.id !== id)), file);

// On from off starts from the assistant's reply at that moment: nothing older is texted.
export function setMessagesOn(on: boolean, file = configFile(), state = messagesFile()) {
  const was = messagesOn(file);
  const m = (readConfig(file) as { messages?: unknown }).messages;
  saveConfig({ messages: { ...(m && typeof m === "object" && !Array.isArray(m) ? m : {}), on } }, file);
  if (on && !was) change((s) => void (s.primed = false), state);
}

export function readRelayKey(dir = blimpDir()): string {
  try {
    return readFileSync(relayKeyFile(dir), "utf8").trim();
  } catch {
    return "";
  }
}

// Made if it's missing or empty: 32 random bytes as hex, readable only by you.
export function makeRelayKey(dir = blimpDir()): string {
  let key = readRelayKey(dir);
  if (!key) writeFileSync(relayKeyFile(dir), (key = randomBytes(32).toString("hex")), { mode: 0o600 });
  chmodSync(relayKeyFile(dir), 0o600);

export function runMessages(args: string[], dir = blimpDir(), now = Date.now()): number {

    return 1;

    makeRelayKey(dir);
    console.log(`Texting is on. The relay's key is in ${relayKeyFile(dir)}: copy it into the relay's relay.json.`);

        s.relaySeen === undefined ? "The relay hasn't called yet." : `The relay last called ${ago(now - s.relaySeen)} ago.`,
        `${n} ${n === 1 ? "text is" : "texts are"} waiting to go out.`,

// What blimp texts, and how it reads a texted reply (docs/superpowers/specs/2026-10-26-messages-design.md,
// section 2): the assistant's answers as plain text, its questions as a text, and a reply as an answer to one, in the
// shape answer.ts takes.

import type { Prompt } from "../prompt";

export const OFF = "The assistant is off. Turn it on in blimp's Settings.";
export const PICTURE_ONLY = "I can only read text for now.";
export const PICTURE_NOTE = " (a picture came with this text; you can't see pictures yet)";
export const ALREADY = "That was already answered.";
export const OPEN_BLIMP = "It's asking something only blimp can show. Open blimp to answer.";
export const OFFLINE = "The Messages relay is offline: blimp hasn't heard from it in 5 minutes. Check the Mac it runs on.";

// Markdown as a text: as push/payload.ts's plainText, but with line breaks (at most one blank line in a row), list
// marks and link addresses kept.
export function plainLines(md: string): string {
  return md
    .replace(/^[ \t]*```.*$/gm, "")
    .replace(/!\[([^\]]*)\]\([^)]*\)/g, "$1")
    .replace(/\[([^\]]*)\]\(([^)\s]+)\)/g, (_, words: string, url: string) => (words && words !== url ? `${words} (${url})` : url))
    .replace(/^[ \t]{0,3}(?:#{1,6}|>)[ \t]+/gm, "")
    .replace(/(\*\*|__|~~)(.+?)\1/g, "$2")
    .replace(/\*(\S[^*\n]*?)\*/g, "$1")
    .replace(/`([^`\n]*)`/g, "$1")
    .replace(/[ \t]+$/gm, "")
    .replace(/\n{3,}/g, "\n\n")
    .trim();
}

const clip = (s: string, n = 600) => (s.length > n ? s.slice(0, n - 1) + "…" : s);
// mcp__claude_ai_Gmail__send_message: Gmail send message.
const toolName = (tool: string) => tool.replace(/^mcp__/, "").replace(/^claude_ai_/, "").replace(/_+/g, " ").trim();
// The one question of a dialog a text can answer: one question, one choice.
const single = (p: Prompt) => (p.kind === "question" && p.answerable && p.questions.length === 1 && !p.questions[0].multiSelect ? p.questions[0] : undefined);

export function waitText(p: Prompt): string {
  if (p.kind === "permission") return [p.tool === "Bash" ? "OK to run this?" : `OK to use ${toolName(p.tool)}?`, ...(p.summary ? [clip(p.summary)] : [])].join("\n") + "\n\nReply yes or no.";
  const q = single(p);
  if (q) return `${q.question}\n${q.options.map((o, i) => `${i + 1}. ${o.label}`).join("\n")}\n\nReply with a number or your own words.`;
  return OPEN_BLIMP;
}

const YES = /^(yes|y|ok|okay)[.!]?$/i;
const NO = /^(no|n)[.!]?$/i;
const NUMBER = /^(\d+)[.!]?$/;

// A reply that only makes sense as an answer: one that comes after its question was answered elsewhere isn't typed.
export const isShortAnswer = (text: string) => [YES, NO, NUMBER].some((re) => re.test(text.trim()));

// The answer.ts message for a texted reply to the wait p, or undefined when a text can't answer it.
export function replyFor(p: Prompt & { at: number }, text: string): Record<string, unknown> | undefined {
  const t = text.trim();
  if (p.kind === "permission") {
    const yes = p.options.findIndex((o) => /^yes\b/i.test(o));
    const no = p.options.findIndex((o) => /^no\b/i.test(o));
    if (YES.test(t)) return yes < 0 ? undefined : { type: "answer", at: p.at, pick: yes, label: p.options[yes] };
    if (NO.test(t)) return no < 0 ? undefined : { type: "answer", at: p.at, pick: no, label: p.options[no] };
    return { type: "deny", at: p.at, text: t };
  }
  const q = single(p);
  if (!q) return undefined;
  const n = NUMBER.exec(t);
  const i = n ? Number(n[1]) - 1 : -1;
  if (i >= 0 && i < q.options.length) return { type: "answer", at: p.at, answers: [{ picks: [i] }], labels: [[q.options[i].label]] };
  return { type: "answer", at: p.at, answers: [{ text: t }], labels: [[]] };
}

// The texting loop (docs/superpowers/specs/2026-10-26-messages-design.md, section 2).
// - Texts in from the relay answer the question last texted, or wait in the state file's `held`.
// - Every second:
//   - the assistant's finished turns and its questions become texts out (the outbox, which the relay takes);
//   - held texts are typed into it once it isn't asking anything;
//   - a relay that's been quiet for 5 minutes is told to the phone, once.

import { answerOnce } from "../answer";
import { ASSISTANT, assistantOn } from "../assistant";
import { HttpError } from "../files";
import { follow, newSummary, type Summary } from "../names";
import { cleanText } from "../prompt";
import { Apns, HOSTS } from "../push/apns";
import { ASK_SETTLE } from "../push/rule";
import { readCreds, readDevices } from "../push/store";
import type { Session } from "../sessions";
import { Asking, findSession, typeInto } from "../typing";
import { addOut, change, messagesFile, messagesOn, pushOut, readState, SEEN } from "./store";
import { ALREADY, isShortAnswer, OFF, OFFLINE, PICTURE_NOTE, PICTURE_ONLY, plainLines, replyFor, waitText } from "./words";

export const QUIET = 5 * 60_000;
const MAX_TEXT = 20_000;

export type TexterDeps = {
  on: () => boolean;
  assistantOn: () => boolean;
  session: () => Promise<Session | undefined>; // the assistant's
  reply: (transcript: string) => Promise<{ id?: string; text?: string }>; // its latest reply
  type: (text: string) => Promise<void>; // into the assistant; throws Asking while it asks something
  answer: (id: string, m: Record<string, unknown>) => Promise<void>; // answer.ts's answerOnce for the assistant
  alert: (body: string) => Promise<void>; // to the phones
  file: string; // messages.json
  now: () => number;
  log: (m: string) => void;
};

export class Texter {
  private busy = false;
  private started: number;
  private relaySeen?: number;
  private alerted = false;

  constructor(private deps: TexterDeps) {
    this.started = deps.now();
  }

  // The relay called.
  touch() {
    const now = this.deps.now();
    this.relaySeen = now;
    this.alerted = false;
    change((s) => void (s.relaySeen = now), this.deps.file);
  }

  // Texting is on and the relay called within 5 minutes: the texts are the assistant's alerts (push/rule.ts).
  live(): boolean {
    return this.deps.on() && this.relaySeen !== undefined && this.deps.now() - this.relaySeen < QUIET;
  }

  // A text from the relay.
  async receive(body: unknown): Promise<{ ok: true; dup?: true }> {
    const t = (body ?? {}) as { id?: unknown; from?: unknown; text?: unknown; picture?: unknown };
    if (typeof t.id !== "string" || !t.id || t.id.length > 200 || typeof t.from !== "string" || t.from.length > 200 || typeof t.text !== "string" || t.text.length > MAX_TEXT || (t.picture !== undefined && typeof t.picture !== "boolean"))
      throw new HttpError(400, "expected a text: {id, from, text, picture?}");
    const id = t.id;
    const file = this.deps.file;
    const dup = change((s) => {
      if (s.seen.includes(id)) return true;
      s.seen = [...s.seen, id].slice(-SEEN);
      return false;
    }, file);
    if (dup) return { ok: true, dup: true };
    const say = (words: string) => addOut(words, this.deps.now(), file);
    if (!this.deps.assistantOn()) {
      say(OFF);
      return { ok: true };
    }
    let text = cleanText(t.text).trim();
    if (t.picture && !text) {
      say(PICTURE_ONLY);
      return { ok: true };
    }
    if (t.picture) text += PICTURE_NOTE;
    const s = await this.deps.session();
    const st = readState(file);
    const p = s?.state === "waiting" && s.prompt?.at === st.lastWait ? s.prompt : undefined;
    if (p && st.open) {
      const m = replyFor(p, text);
      if (m) {
        change((x) => void (x.open = false), file);
        try {
          await this.deps.answer(id, m);
        } catch (e) {
          const why = (e as Error).message;
          say(why === "the question changed" ? ALREADY : `Couldn't answer that: ${why}`);
        }
        return { ok: true };
      }
    } else if (!p && st.open && isShortAnswer(text)) {
      change((x) => void (x.open = false), file);
      say(ALREADY);
      return { ok: true };
    }
    change((x) => void x.held.push(text), file);
    return { ok: true };
  }

  async tick(): Promise<void> {
    if (this.busy) return;
    this.busy = true;
    try {
      if (!this.deps.on()) return;
      const now = this.deps.now();
      const file = this.deps.file;
      if (!this.alerted && now - Math.max(this.relaySeen ?? 0, this.started) >= QUIET) {
        this.alerted = true;
        await this.deps.alert(OFFLINE).catch((e) => this.deps.log(`messages: couldn't tell the phone the relay is quiet (${(e as Error).message})`));
      }
      const s = await this.deps.session();
      if (!s) return;
      // Its reply, once its turn is over and it's one not texted yet. The first look only notes the latest one.
      if (!readState(file).primed) {
        const r: { id?: string } = s.transcript ? await this.deps.reply(s.transcript) : {};
        change((x) => {
          x.primed = true;
          x.sentReply = r.id;
        }, file);
      } else if (s.state === "done" && s.transcript) {
        const r = await this.deps.reply(s.transcript);
        if (r.id && r.id !== readState(file).sentReply) {
          const words = plainLines(r.text ?? "");
          change((x) => {
            x.sentReply = r.id;
            x.open = false;
            if (words) pushOut(x, words, now);
          }, file);
        }
      }
      // Its question, once it has asked for 3 s: texted once.
      const p = s.state === "waiting" ? s.prompt : undefined;
      if (p && now - p.at >= ASK_SETTLE && p.at !== readState(file).lastWait)
        change((x) => {
          x.lastWait = p.at;
          x.open = true;
          pushOut(x, waitText(p), now);
        }, file);
      // Held texts, once it isn't asking anything.
      const held = readState(file).held;
      if (held.length && s.state !== "waiting") {
        try {
          await this.deps.type(held.join("\n\n"));
          change((x) => void (x.held = x.held.slice(held.length)), file);
        } catch (e) {
          if (!(e instanceof Asking)) this.deps.log(`messages: couldn't type a text into the assistant (${(e as Error).message}); trying again`);
        }
      }
    } catch (e) {
      this.deps.log(`messages: ${(e as Error).message}`);
    } finally {
      this.busy = false;
    }
  }

  // The texts to send: as soon as there are some, or none after ms (real time: the relay holds its request open).
  async waitOut(ms: number, signal?: AbortSignal): Promise<{ id: string; text: string }[]> {
    const end = Date.now() + ms;
    for (;;) {
      const out = readState(this.deps.file).outbox;
      if (out.length || Date.now() >= end || signal?.aborted) return out.map(({ id, text }) => ({ id, text }));
      await Bun.sleep(Math.min(250, Math.max(end - Date.now(), 1)));
    }
  }
}

// The latest reply's id and text, read on from where it was, one transcript at a time (the assistant's).
let summary: { file: string; sum: Summary } | undefined;

const live = (): TexterDeps => ({
  on: () => messagesOn(),
  assistantOn: () => assistantOn(),
  session: () => findSession(ASSISTANT),
  reply: async (file) => {
    if (summary?.file !== file) summary = { file, sum: newSummary() };
    await follow(file, summary.sum);
    return { id: summary.sum.replyId, text: summary.sum.reply };
  },
  type: (text) => typeInto(ASSISTANT, text, { enter: true }),
  answer: (id, m) => answerOnce(ASSISTANT, `messages-${id}`, m),
  alert: async (body) => {
    const creds = readCreds();
    const devices = readDevices();
    if (!creds || !devices.length) return console.log(`messages: ${body} (no phone to tell)`);
    const apns = new Apns(creds, HOSTS);
    try {
      for (const d of devices) await apns.send(d, { aps: { alert: { title: "blimp", body }, sound: "default" } });
    } finally {
      apns.close();
    }
  },
  file: messagesFile(),
  now: Date.now,
  log: (m) => console.log(m),
});

let texter: Texter | undefined;
export const theTexter = () => (texter ??= new Texter(live()));

// Every second; it reads nothing while texting is off.
export function startMessages(every = 1000) {
  setInterval(() => void theTexter().tick(), every);
}

// see serve), or the relay's (only /messages/, see serve).
function authorized(req: Request, url: URL, token: string, dir: string): "mac" | "widget" | "relay" | { phone: string } | undefined {
  // HTTP sends a Bearer header; WebSockets can't, so they send ?token=.
  const h = req.headers.get("authorization");

```md
### Texting the assistant

You can text the assistant from Messages instead of opening blimp. A small program, blimp-relay, runs on a Mac that stays on, in a Mac user whose Messages is signed in to an Apple ID made just for the assistant. It passes your texts to blimpd and texts the assistant's answers back.

- Only texts from the phone numbers and email addresses in the relay's list reach the assistant. Group chats and tapbacks are ignored, and pictures aren't read yet.
- Everything the assistant finishes saying is texted to you, including its reports on jobs. Its chat in blimp shows the same conversation.
- When it asks before acting, you get a text like "OK to run this? … Reply yes or no." Other words count as no and go to the assistant as what to do instead. A numbered question takes a number or your own words.
- While the relay works, the assistant's own questions and answers come as texts, not blimp notifications. Jobs that need you still notify from blimp.
- If blimpd hasn't heard from the relay for 5 minutes, your phone gets one notification. After the Mac restarts, sign that Mac user back in.

To set it up:

1. Make an Apple ID from an email address, for the assistant.
2. On the Mac, add a standard user. Sign in to it, open Messages and sign in with that Apple ID.
3. On the server, run `blimpd messages on`. It makes the relay's key, `~/.blimp/relay-key`.
4. Build the relay with `bun run relay` (it makes `dist/blimp-relay`). Copy it to `/Users/Shared/blimp-relay` on the Mac, with `relay/install.sh` and a `relay.json`. `server` is the address the phone uses:

   ```json
   {"server": "https://your-server.your-tailnet.ts.net", "key": "<the relay key>", "allow": ["+15551234567", "you@example.com"]}
   ```

   Without `server`, the relay texts back `got: <your text>`. That tests the Mac on its own.
5. Still signed in as that Mac user, run `bash /Users/Shared/blimp-relay/install.sh` and give blimp-relay Full Disk Access when it asks. Then text the account from your phone, and click OK when macOS asks whether blimp-relay may control Messages.
6. Switch back to your own Mac user, and leave the other one signed in.

Other commands:
- `blimpd messages status` says when the relay last called.
- `blimpd messages off` turns texting off.
- `blimpd messages revoke` deletes the relay's key.
```
